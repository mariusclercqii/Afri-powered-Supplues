# Afri-Powered website (static)

- `public/` is the whole website. Cloudflare serves this folder.
- **Banner on the home page:** edit `public/data/promos.json`. Each slide has tag, title, sub, price, image, link, cta, and optional start/end dates (YYYY-MM-DD).
- **Products:** edit `public/data/products.json` (shop + filters). Product pages are in `public/product/`.
- **Hero photo:** put `hero.jpg` (the ai-generated-8104750_1280.jpg picture) in `public/assets/`.
